# AI 语音通话（实验）

AI 用微信语音通话和人实时对话：控制台按钮拨打、定时电话、自动接听。代码在 `core/voice_call.py`。

## 怎么用

- **控制台 → 语音通话**：选人、填事由（可空）→「拨打」；实时看通话状态和对话，能挂断；看通话记录（对话、各轮延迟、对方录音）。
- **定时电话**：在微信里对机器人说「明天早上 8 点给我打电话提醒我吃药」，或在「定时任务」页一句话创建。到点 AI 打过去说这件事，对方说知道了就道别挂断；没接通 / 当时在通话里 → 改发文字提醒（可关）。
- **自动接听**：名单里的人打来，AI 自动接起来聊（「喂，怎么啦？」提前合成好，接起来就说）。
- **设置**：可拨打 / 自动接听名单（空 = 只允许测试号 🐮🐮🌱besos）、是否允许名单外的人在聊天里让机器人给他自己打电话、每通最长分钟数、没接通改发文字、会话不在最近列表时先发的一句话。

命令行（调试用）：

```bash
docker exec -u wechat wxbot-ubuntu-manual sh -c 'cd /app && python3 tools/voice_call.py --selftest --purpose 提醒吃药'
docker exec -u wechat wxbot-ubuntu-manual sh -c 'cd /app && python3 tools/voice_call.py --dial wxid_xxx --purpose 提醒吃药'
```

## 拨号前怎么确保打对人

1. 主窗口缩到托盘就点托盘图标叫出来（wmctrl / windowmap 叫不出来）。
2. 标题 OCR（放大 2 倍、单行）严格核对：名字里的汉字都要在；表情会被认成怪字，按表情个数容忍；
   和它相似的联系人（如「蜜蜜🌱besos」之于「🐮🐮🌱besos」）独有的字出现了就一定不是。
3. 不是当前会话就在最近会话列表里 OCR 找（列表字小，≥3 个汉字的名字容 1 个错字，只用来挑候选，点开后仍按第 2 条严格核对）。
4. 列表里没有 → 先直发一句「等下给你打个电话～」把会话顶上来再找。
5. 点电话图标后核对出现了「语音通话」菜单、点了之后核对出现了通话窗口，否则重试一次，再不行就放弃（不会对着桌面空等）。

## 怎么做的

| 环节 | 做法 |
| --- | --- |
| 拨号 / 接通 / 挂断 | xdotool 点聊天右上角电话 → 「语音通话」；通话窗口 OCR 到计时 `00:00` 算接通（或先听到对方说话）；挂断点通话窗口底部 |
| 我们说话 | 合成的声音播进 PulseAudio `vmic` → `virtual_mic`（微信的麦克风） |
| 听对方 | 默认输出改成 `vspk`，录 `vspk.monitor` → 阿里云 `paraformer-realtime-v2` 实时识别（700ms 静音算一句） |
| 想 | 人设先浓缩成 300 字「通话角色卡」（按内容缓存），只带最近 8 条对话，AI 流式输出 |
| 说 | CosyVoice 流式合成（对方一停就提前建好合成会话，省 ~1.1 秒），边合成边播 |
| 轮次 | 不排队：攒下的话合成一句回；AI 还没开口对方又说话 → 取消、合并、重想；对方说 ≥3 个汉字就打断我们；过滤 Yeah/单字碎片和回声 |

每通电话的录音（`remote.wav`）、识别、回复和各环节耗时在 `work/voice_calls/<时间>/events.jsonl`。

## 实测（2026-11-29 续）

| 场景 | 结果 |
| --- | --- |
| 提醒电话（控制台拨，事由「提醒喝水」） | 接通 0.3 秒开口说提醒；对方说好 → 道别挂断，22 秒 |
| 自动接听（besos 打给主号） | 自动接起，两轮回复 2.8 / 3.0 秒，说晚安拜拜后挂断；接起后开口原来要等 11.6 秒，已改成预合成 |
| 定时电话（自然语言「3 分钟后给 besos 打电话提醒喝水」） | 准时触发；那次主窗口被缩到托盘没拨出 → 加了托盘恢复和拨号核对；没接通时文字提醒照发 |

坑：
- 来电弹窗「邀请你语音通话」的「邀」常认成「六」；接听按钮没有文字，按绿色像素找。
- 两个号不是好友时，直发会报 submitted，但微信里是红色感叹号（没发出去）。
- 第 1 通把自己的录音器也挪到了麦克风上，录的一直是自己 → 只挪微信自己的流。
- 「夏以昼」会被识别成「下宇宙」「下一周」→ 规则里提示 AI；后续可加识别热词。
- 自动打电话比发消息更容易触发风控，只在测试号之间用。
